## Mission 1 — Assumption Ledger build (2026-11-06)

### Verified Hermes extension facts (HEAD 486f4a6a9918a4054373e33a200260ffd501645e, v0.23.0)
- Directory plugin layout: repo root needs `plugin.yaml` + `__init__.py` exposing `register(ctx)`.
  The loader (`plugins/plugin_loader.py::_load_plugin_module_locked`) puts the plugin dir on the
  module path and also loads every top-level `*.py` in that dir as a submodule — so a sibling
  package dir (`ledger/`) works with a plain `from ledger import ...` inside the plugin.
- `register_command(name, handler, description="", args_hint="", argument_mode=None)`;
  handler is `fn(raw_args: str) -> str | None`. `args_hint` needed for Discord arg field.
- `pre_verify` returns `{"action": "continue", "message": ...}` to keep an edited-code turn going;
  bounded by `agent.max_verify_nudges`. Anything else finishes the turn.
- `pre_llm_call` returning `{"action": "block", "message": ...}` vetoes BEFORE any model call
  (exit reason `blocked_by_plugin_pre_llm_call`); returning `{"context": str}` appends to the
  user message (`plugin_user_context`). Both are real — confirmed in agent/turn_context.py.
- `VALID_MIDDLEWARE` = {tool_request, tool_execution, llm_request, llm_execution}.
- Storage: `plugins.plugin_storage.plugin_data_dir(name)` / `plugin_db(name)` is the sanctioned
  durable home; survives `hermes plugins update`/`remove`, follows the active profile.
  Do NOT write runtime state into the plugin install dir.
- Catalog: `plugin-catalog/<name>.yaml` in NousResearch/hermes-agent. `repo` may be **GitHub or
  GitLab** (https only); `sha` must be full 40-hex; `category` ∈
  desktop|memory|platform|web|tools|voice|automation|models|general (default desktop);
  `tier` official|verified|community (contributor PRs are forced to community).
  Entry schema + admission rules: plugin-catalog/README.md.
- `hermes plugins validate <dir>` runs 15 checks incl. "declared tools/hooks/middleware match
  registrations" and a security scan. `hermes plugins doctor <dir>` loads through the real runtime.
